# Good Life Lending website

Static site for https://goodlife-lending.com, hosted on GitHub Pages (published from `docs/`).

- Edit content in `src/` (`home.html`, `site.css`, `build.py`), then run `python3 src/build.py` and commit `docs/`.
- Lead capture uses the GoHighLevel embeds (Instant Quote survey, Loan Request form), so GHL workflows keep firing.
- Tracking (GA4 G-235FJNCR9P, GTM-KV8DJBX7, Meta Pixel 669608049332732, Search Console, GHL external tracking) is injected on every page by `build.py`.
